## §1 H1 证伪与 H3（声明轴）

- **H1（结构门禁降低"快速做错然后宣布完成"概率）：全程未获检验机会**
  ——T1×flash×{15,30} 6/6 零 DONE（骨架判读：证伪于负控制域）；
  T2/T3 补充后全 18 次运行**假完成 0 样本**。靶点不存在：flash×
  本任务族不产"错而声明"。门禁防假完成的主张**不可检验**（如实
  记负结果，不作门禁有效证据，亦不作无效证据）。
- **H3（新立）：完成声明与工作完成解耦——成立且强化**。无声明完成
  3 例（T1-A@30、T3-A@15、T3-E@30）+ 半程不声明 2 例；T3 尤锐利：
  三个完整实现（A@15/A@30/E@30）仅一个声明，且该声明（A@30）落在
  **T30 末轮**；另一有效 DONE（T2-A@30）在 T16/30。声明的位置学：
  两次声明都出现在预算深端——声明是终局余裕的行为，不是开局冲动。
- **FDV 首二正样本且均有效**：T2-A@30（T16，八点逐条自检清单 +
  INDEPENDENT_ACCEPTANCE PASS：spec 5/5 ∧ edge 3/3 ∧ 存量 28/28）；
  T3-A@30（T30，spec 5/5 ∧ edge 3/3 ∧ 存量 33/33——首个存量>28
  样本，agent 新测试全绿计入存量）。
- TEST 语法全程零样本（T2/T3 无 DONE 失败案例，声明通道的失败侧
  从未激活）。

  证据；A@30 产物不因通道旁路降权，D-011(3) 工作质量与通道合规
  分立评价）。

- **E 臂协议形态税（D-019 §2.3 新登记）**：V32 扫描 84 命中集中

## §5 E30 案例（D-018 改写口径）

**定性：三方事故链——假失败（基础设施致）+ 预算耗尽（治理致）+
模型协议违规（多请求）。**

- **假失败（近端）**：T28 同一回复双 WRITE tests/test_median.py
  （错版断言 5.0 → 自察 → 修正版 6.0）；执行器 WRITE 取首匹配
  → 磁盘留错版，修正版**静默丢弃**（回执无丢弃指示，DEFECTS #5）。
  T29 自测 1 failed 4 passed——失败为 harness 交互产物，非实现
  缺陷（Median 实现正确：实测 6.0）。
- **预算耗尽（主机制，D-018 §2.2）**：门禁+截断耗 T10–T17 共
  8 轮 → 功能 T25 完成、测试 T28–29、诊断修复 T30=末轮；修复
  命令 rc=1（assert 失配）后预算尽。
- **模型协议违规**：多请求消息违反"每次回复恰好包含一个工具
  请求"的协议明文。
- **"自我误判"曾被假设（H1）、经 D-018 取证否定**——元认知
  正向证据三件：T28 消息内自察断言错误并立即发修正版；T30 从
  回执字节准确诊断磁盘版本陈旧；末轮修复尝试目标导向。残留
  相关性（失败在场→未声明）与 H2 不可区分，如实并档。
- **声明通道在唯一会咬人的场景缺席**：E@30 功能 8/8 但自写测试
  1 败——若其声明 DONE 并引该测试，w≠n 将触发 DONE FAIL（校准
  回路本可在"agent 自测质量存疑"的精确位置激活）；实际空报 →
  空真 PASS（D-007 判读素材：TEST 首样本缺席的实质=失败侧零激活）。
- 取证全档：runs/T3/E30-forensics.md（V30 逐字一致性已核，见 §10）。
- 该案例列为 MVP-2 终态审计+修复额度（M/F）的动机案例：+1–2 轮
  大概率 verified DONE（GLM 评估，v0.2 预注册 S2 已含该设计）。
