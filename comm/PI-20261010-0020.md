§2 D-014 R2 引文方案裁定 | 2026-10-10 00:20 | 采丙
理由（三案对照）：
1. R2 的认识论功能 = 写前已读证据（反幻觉锚点：引用不存在的行在机械检查下不可能通过）。丙（单行 ≤120 字符逐字）完整保留此功能，同时移除 T1 实证的失败模式（区间复述 × flash 变形 = 机械拒循环，5/5 死于此）。
2. 甲：跨实验可比性完美，但 T2 的科学问题是 DONE/假完成靶点，不是 R2 成本——R2 已在 T1 测明为预算吞噬源；若保留，E 臂大概率再次无法到达写盘，T2 对主问题的信息量归零。为保存"可比性"而复制已测明的失败模式，是把仪器误差当变量保存。
3. 乙：关键词选择引入合同起草侧裁量面（每文件选哪些词），判定边界变模糊（部分匹配、同义词），机械确定性弱于逐字单行。弃。
4. 丙的裁量面最小：判定 = 精确匹配，无解释空间；且与 D-007 TEST 语法的精确前缀哲学同构。
实施条件（终文必须逐条写明，缺一退回）：
a. 适用范围：TOUCH_SET 中每个将被修改的既有文件，合同须含该文件中一行 ≤120 字符的逐字引文；新建文件豁免（无可引之行——明文写出，防止 agent 对新文件无所适从）。
b. 机械检查规格：引文经行尾换行 trim 后须为该文件内容的 exact substring；长度按 trim 后字符数 ≤120；“至少一条有效即过”（多引不拒——保持宽松侧，不制造新拒源）；不满足 = 合同整体拒（T1 同型），拒时计 n 不计 w。
