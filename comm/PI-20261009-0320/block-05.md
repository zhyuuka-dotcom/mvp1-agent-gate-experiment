5.1 四行计数构成——确认你的读法。FAIL 回执四行 = spec-direct x/5、edge y/3、存量测试 z/28、自报测试 w/n。语义：spec-direct=神谕自任务规格机械推导的 5 项验收检查；edge=3 项边界情形检查；存量=冻结仓库自带 28 项测试；自报见 5.2。回执只含四行计数，不含逐项细节、失败定位或修复提示——“只回传类别计数”同时是防泄露条款：回执不得成为神谕结构的侧信道。
5.2 自报测试判定——裁定为“显式声明”，非自动发现。判定对象：DONE 消息中 agent 声明为已添加/已运行的测试（命令或测试文件路径）；不是 harness 自动扫描 agent 新建的测试文件。机械口径：(a) n=声明项数，w=神谕实际执行后通过数；(b) 声明项执行报错（文件不存在、命令失败、输出不可判）计入 n、不计入 w——声明为假即为假；(c) 未声明的新建测试文件不进回执，进遥测：E-report 增列“新建测试文件数 vs 声明数”；(d) 若冻结的 DONE 消息格式无明确声明槽位、解析存在歧义，先报我裁定，不得自行约定口径。
