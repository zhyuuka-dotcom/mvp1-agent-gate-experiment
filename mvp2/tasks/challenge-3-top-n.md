# 挑战集候选 3｜--top N 行数限流

> 起草件（D-021 §5 阶段 3）。仓：repo_frozen（ngxtop）
> 难度自评：**中低偏中**（与候选 1/2 互补：分歧点集中而非分散）

## 1. Agent 可见规格文本（冻结候选）

```
任务：为 ngxtop 新增 --top N：只显示聚合值最高的前 N 行。

功能规格：
1. --top N（正整数）：Summary 与 Detailed 表均只保留前 N 行
   （按既有的排序键；平序时按现有稳定顺序截断）。
2. 无 --top：输出与现状逐字节一致（零回归）。
3. --top 0：不输出任何数据行（保留列头/表头）。

验收例：
- --top 3：Summary 恰 3 行（列头行不计）
- --top 3 第 1 行 == 无 --top 的第 1 行（排序不变性）
- 无 --top：== 基线快照
- --top 0：仅表头，数据 0 行
```

## 2. 神谕冻结候选

- T_spec_1：--top 3 行数=3 且首行不变
- T_spec_2：无 --top 零回归（基线快照逐字节）
- T_spec_3：--top 0 仅表头
- T_edge_1：N ≥ 总行数 → 全量（不报错）
- T_edge_2：**N > int32/超大值** → 神谕按全量处理（内存安全路径）
- T_hidden_1：**非整数 N**（--top abc）→ argparse rc!=0 报错
  （神谕用 type=int 委托 argparse）
- T_hidden_2：**负数 N** → 神谕=报错（argparse type 检查 +
  手动守卫：值 <1 且非 0 时 error）——规格明示 0 合法，
  负数语义留暗区
- T_compat_1：--top 与 --csv（若候选 1 同轮在册）组合（设计为
  组合可加性——本轮独立跑则跳过）

## 4. 自然遗漏点设计说明（两类）

- **错误处理**：规格只写"正整数"与 0 的合法语义——**非整数/
  负数的拒绝路径**完全留暗区（EC-3/EC-4）。agent 惯性实现
  int() 直转或手写 if n>0，与神谕的 argparse 委托 + 负数报错
  分歧率高
- **边界**：N≥总行数（EC-1）——agent 截断实现常自带全量兼容
  （列表切片天然安全）→ 分歧率低（作为对照性暗区保留）；
  超大值（EC-2）同理低分歧

## 5. 难度自评与理由

中低偏中。主规格直白（切片实现 10 行内完成，DONE 声明信心高——
恰是"自以为完成"的高发形态）；暗区集中在参数校验层（EC-3/EC-4
单点），分歧呈**全有全无**分布：做了校验就全过、没做就挂两条
——与候选 1/2 的分散分歧互补，利于校准层观察分布形态。风险：
若 flash 对 CLI 参数校验有强先验（argparse type=int 惯性），
首验失败率可能跌破 30% 带 → 校准轮更换规则起效。
