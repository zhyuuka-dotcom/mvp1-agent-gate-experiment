# R2 引文机械可满足性方案（D-013(2) 送审件，不预设结论）

> 背景：D-012(2) 将"R2 逐字比对 × flash 复述变形 = 合同机械拒主因"记为
> 机制发现；D-013(2) 要求 mechanics_T2 草稿提出具体方案，由 PI 审阅裁定。
> 本件给三方案 + T1 实测数据 + 执行者推荐（仅供参考，裁量在 PI）。

## T1 实测数据（六个门禁臂）

| 臂 | 合同提交 | 拒绝 | 拒因 |
|----|----------|------|------|
| C@15 | 0 | — | 未触发门禁 |
| C@30 | 2 | 2 | **全部 R2**（引文未逐字出现×3 条/次） |
| E@15 | 0 | — | 未触发门禁 |
| E@30 | 4 | 3 | **全部 R2**；第 4 次通过（a4） |

合计：6 次提交、5 次拒绝、**5/5 死于 R2 引文逐字比对**（0 次死于
R1/R3/R4）。唯一通过（E@30 a4）发生在 agent 于 T29 用 `sed -n` 逐行
提取原文后回填——证明机制可满足，但代价≈一整轮预算（T1 判读：
"死的是预算经济学不是机械故障"）。

## 三方案

| | 甲：区间内逐字引文（T1 原案） | 乙：区间关键词组 | 丙：区间内单行短引文 |
|--|--|--|--|
| 合同写法 | 依据行区间 + 逐字引文 | 依据行区间 + ≥3 关键词组按序 | 依据行区间 + 任选区间内一行（≤120 字符）逐字 |
| 机械校验 | 空白归一化后子串匹配 | 区间文本内按序子串命中 | 引文=区间内某整行（空白归一化） |
| 锚定强度 | 最强（必须精确复制） | 中（须知道真实行号+真实词） | 强（须复制真实行） |
| flash 可满足性 | 差（实测 5/5 拒） | 好 | 好（单行复制≈sed 提取的低配） |
| 信息泄露面 | 无 | 词组可被猜测绕过（低概率） | 无 |
| 与 T1 可比性 | 完全可比 | 变更门禁变量（混入"放松"因素） | 变更但保逐字纪律 |

## 执行者推荐：丙

理由：保留"逐字"机械确定性（校验器仍是确定性子串/整行匹配，无语义
裁量）同时把复述负担从"多行长引文"降到"一行"——T1 唯一通过样本
（sed 提取后回填）证明 flash 能做到单行级精确。乙的按序词组引入
部分自由度，锚定弱化且校验器复杂度上升。甲保持原样则 T2 大概率
复刻 T1 的 R2 拒循环（合同成本再次≈一整轮预算），测的仍是预算经济
学而非 T2 想测的执行纪律。

判读注意事项（如实）：选乙或丙会在"C/E 臂门禁变量"上引入与 T1 的
差异——六臂对照时须标注"合同条款代差"，终报 §3 按此口径解读。
